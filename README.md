## 📌 Problem Statement

**Community Hero – Hyperlocal Problem Solver**

Communities often face issues such as potholes, water leakages, damaged streetlights, waste accumulation, unsafe roads, and other public infrastructure challenges.

Traditional reporting systems are fragmented, difficult to track, and provide little transparency.

**CivicForce AI** uses Google Gemini to intelligently understand, investigate, prioritize, and help resolve civic issues through AI-powered automation.

# 🧠 Google Gemini Integration

Gemini is the core intelligence engine of CivicForce AI.

It performs:

- Multimodal reasoning
- Speech understanding
- Image understanding
- Issue categorization
- Root cause reasoning
- Severity prediction
- AI Investigation generation
- Department recommendation
- Action planning

Unlike traditional reporting platforms, CivicForce AI combines voice, images, videos, and GPS context into a single intelligent investigation workflow.

# ⚙ Installation

Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/CivicForce-AI.git
```

Go into the project

```bash
cd CivicForce-AI
```

Install dependencies

```bash
npm install
```

Create a `.env.local`

```env
GEMINI_API_KEY=YOUR_API_KEY
```

Run

```bash
npm run dev
```
